## Общие принципы моков

- Все моки возвращают JSON.
- Ошибка источника: `503 Service Unavailable` → retry 3 раза → ручная проверка.
- Не найден: `404 Not Found`.
- Для демо: мок имеет режим «сломаться» на конкретном ИНН.
