# ЦБ — Платформа «Знай своего клиента» (ЗСК)

## Владелец

Банк России.

## Доступ

- Работает с 01.07.2022.
- **Для банков:** закрытый канал, техническая документация только для участников платформы.
- **С 01.10.2024:** внешний сервис позволяет узнать, относится ли ИП/ЮЛ к категории высокого риска (красный).
- **Публичного API нет.**

## Что берём для конвейера

ЦБ присваивает каждому ЮЛ и ИП один из трёх уровней риска:

| Уровень | Цвет | Что значит | Действие в конвейере |
|---|---|---|---|
| Низкий | Зелёный | Компания не вызывает подозрений | проходит дальше |
| Средний | Жёлтый | Есть признаки подозрительной деятельности | повод для ручной проверки 6 |
| Высокий | Красный | Значительные признаки отмывания / финансирования терроризма | стоп-фактор 6 → отказ |

Информация для банков носит **рекомендательный** характер — окончательную оценку банки присваивают самостоятельно.

## Контракт мока

```
GET /api/mock/cbr-kyc/{inn}

Response 200:
{
  "inn": "7726402390",
  "risk_level": "green",             // green | yellow | red
  "risk_level_date": "2026-10-15",   // дата последнего обновления
  "entity_type": "legal"             // legal | individual
}

// Жёлтый уровень — повод для ручной проверки
{
  "inn": "7799887766",
  "risk_level": "yellow",
  "risk_level_date": "2026-09-20",
  "entity_type": "legal"
}

// Красный уровень — стоп-фактор
{
  "inn": "7788776655",
  "risk_level": "red",
  "risk_level_date": "2026-10-01",
  "entity_type": "individual"
}

Response 404:
{"error": "not_found", "message": "ИНН не найден в платформе ЗСК"}

Response 503:
{"error": "service_unavailable", "message": "Платформа ЦБ не отвечает"}
```

## Примечания

- Самый простой мок из всех источников — один enum на три значения.
- В реальности уровень обновляется ежедневно, ЦБ анализирует операции клиента.
- Для демо: мок возвращает зелёный по умолчанию, красный/жёлтый — для специальных тестовых ИНН.
