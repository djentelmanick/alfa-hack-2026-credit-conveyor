# Проверка ЭП банка (электронная подпись в выписке)

## Владелец

Банк-отправитель выписки. Подпись выдаётся аккредитованным удостоверяющим центром.

## Доступ

- Реальная проверка — через КриптоПро CSP или аналог.
- Для MVP — чистый мок.

## Что проверяем

Многие банки выдают выписку 1С, подписанную усиленной квалифицированной электронной подписью (УКЭП). Если подпись есть и валидна — выписка считается подлинной, выручка подтверждена.

## Контракт мока

Мок максимально простой — по флагу в синтетических данных:

```
GET /api/mock/verify-signature

Body:
{
  "file_hash": "sha256:abc123..."    // хеш загруженного файла выписки
}

Response 200:
{
  "has_signature": true,
  "signature_valid": true,            // true | false
  "signer": "ПАО Сбербанк",
  "certificate_valid_until": "2027-12-31"
}

// Выписка без подписи
Response 200:
{
  "has_signature": false,
  "signature_valid": false,
  "signer": null,
  "certificate_valid_until": null
}

Response 503:
{"error": "service_unavailable", "message": "Сервис проверки ЭП не отвечает"}
```

## Примечания

- Для демо: у тестового сценария 4 (ИП Иванова) выписка идёт с ЭП банка → `signature_valid: true`.
- Если подписи нет и сверка с ФНС не прошла → ручная проверка.
