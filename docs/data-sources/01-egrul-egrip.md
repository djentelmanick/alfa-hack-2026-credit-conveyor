# ЕГРЮЛ / ЕГРИП — Единый государственный реестр юридических лиц / индивидуальных предпринимателей

## Владелец

ФНС России.

## Доступ

- **Официальный веб-сервис:** https://egrul.nalog.ru — поиск по ИНН/ОГРН, выписка в PDF с УКЭП ФНС. Публичного API нет.
- **Коммерческие API:** api-fns.ru, checko.ru, ofdata.ru, damia.ru — JSON, платные с бесплатным лимитом.

В выписке ООО «М-ФУД» три учредителя:
1. Магницкая Е.Н. — 20%
2. Сотир Д.Г. — 56% (он же директор)
3. Матвиец Г.А. — 24%

По скоупу проверяем по БКИ учредителей с долей ≥ 20% — это все трое.

### Из ЕГРИП (ИП)

На основе реальной выписки ИП Зайцев С.А. (ИНН 772426617833) — см. [samples/egrip-ip-zaitsev-772426617833.pdf](samples/egrip-ip-zaitsev-772426617833.pdf):

| ОГРНИП | 324774600530350 | идентификация |
| ИНН | 772426617833 | ключ поиска |
| Дата регистрации | 12.08.2024 | стоп-фактор 2, скоринг |
| Пол | мужской | — |
| Гражданство | гражданин РФ | — |
| E-mail | ZAITSEV5SERGEJS@YNDEX.RU | информационно |
| Основной ОКВЭД | 96.09 Предоставление прочих персональных услуг | стоп-фактор 4, скоринг |
| Статус | действующий | стоп-фактор 1 |

**Отличия от ЕГРЮЛ:**
- Нет учредителей (ИП = физлицо).
- Нет уставного капитала.
- Нет отдельного руководителя — ИП и есть руководитель.
- ИП как физлицо проверяется по БКИ (стоп-фактор 3) и Росфинмониторингу (стоп-фактор 7).
