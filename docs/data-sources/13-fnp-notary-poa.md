# Реестр нотариальных доверенностей (ФНП)

## Владелец

Федеральная нотариальная палата. Реестр учитывает и удостоверение доверенности, и её отмену.

## Доступ

- Реальная проверка — [reestr-dover.ru](https://reestr-dover.ru) по дате удостоверения, реестровому номеру и ФИО нотариуса. Для банков есть машинный доступ: запрос к веб-сервису ФНП через СМЭВ.
- Для MVP — чистый мок на синтетике `backend/app/infra/mocks/data/notary_poa.json`.

## Что проверяем

То же, что у МЧД (`12-fns-mchd.md`): действует и не отменена, доверитель — компания из заявки, подписал действующий руководитель по ЕГРЮЛ, представитель — заявитель, есть оба полномочия.

## Контракт мока

```
POST /api/mock/notary-poa/find

Body:
{
  "notarized_on": "2026-09-15",
  "register_number": "77/123-н/77-2026-4-512",
  "notary_name": "Белова Ирина Александровна"     // без учёта регистра и лишних пробелов
}

Response 200 (найдена):
{
  "found": true,
  "principal": {"inn": "7716012345", "full_name": "ООО \"ПЕКАРНЯ ПЕТРОВЫХ\""},
  "signed_by": {"inn": "771601234560", "full_name": "ЗУЕВ АНДРЕЙ МИХАЙЛОВИЧ"},
  "representative": {"inn": "771402345674", "full_name": "ПЕТРОВА МАРИЯ СЕРГЕЕВНА"},
  "valid_until": "2027-09-15",
  "revoked": false,
  "powers": ["LOAN_APPLICATION", "LOAN_AGREEMENT_SIGNING"]
}

Response 200 (не найдена):
{"found": false}

Response 503:
{"error": "service_unavailable", "message": "Реестр ФНП не отвечает"}
```

## Примечания

- Настоящий реестр ФНП отвечает только «найдена / отменена» и не отдаёт стороны и полномочия. Мок отдаёт больше, чтобы обе доверенности проверялись одинаково; в реальной интеграции стороны и полномочия придётся брать из распознанного скана.
- Для демо: учётка `petrova` (учредитель ООО «Пекарня Петровых», 30%) с доверенностью от 15.09.2026 № 77/123-н/77-2026-4-512 проходит. Доверенность № 77/123-н/77-2026-3-207 отменена, она для тестов.
