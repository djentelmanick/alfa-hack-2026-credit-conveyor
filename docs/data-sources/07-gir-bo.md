# ГИР БО — Государственный информационный ресурс бухгалтерской отчётности

## Владелец

ФНС России.

## Доступ

- **Веб-сервис:** https://bo.nalog.ru — поиск по ИНН/ОГРН, бесплатно, данные с 2019 года.
- **Полная выгрузка:** платное абонентское обслуживание (подключение через bo.nalog.ru).
- **Публичного API нет.**
- **Коммерческие:** ofdata.ru агрегирует данные из ГИР БО и Росстата.

## Что берём для конвейера

Только для **ООО** (у ИП публичной бухотчётности нет).

Используется для **сверки выписки из другого банка** (Should): выручка по выписке, приведённая к году, сравнивается с выручкой из бухотчётности. Расхождение ≤ 20% → выписка подтверждена.

## Примечания

- Отчётность за предыдущий год появляется к апрелю текущего (срок сдачи — 31 марта).
- Выписка охватывает последние 6–12 месяцев, а отчётность — прошлый календарный год. Сравниваем выручку по выписке, приведённую к году, с выручкой из отчётности.
- Расхождение > 20% → ручная проверка (сценарий 7).
- Этот источник в Should, не в Must.
