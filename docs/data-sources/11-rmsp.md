# РМСП — Единый реестр субъектов малого и среднего предпринимательства

## Владелец

ФНС России.

## Доступ

- **Веб-сервис:** https://rmsp.nalog.ru — поиск по ИНН/ОГРН, выписка в PDF с УКЭП ФНС. Бесплатно, без регистрации.
- **API:** ФНС предоставляет открытый API РМСП (в отличие от других своих сервисов).

## Зачем нужен

В скоупе РМСП не упоминается как источник проверок, но даёт полезные данные:
- **Категория МСП** (микро / малое / среднее) — подтверждает, что клиент относится к целевой аудитории.
- **Среднесписочная численность** — дополнительный сигнал для аналитика.
- **Дата включения** — ещё один способ подтвердить возраст бизнеса.
