# ФССП — Федеральная служба судебных приставов

## Владелец

ФССП России.

## Доступ

- **Официальный API** (api-ip.fssp.gov.ru) — **отключён с 10.03.2022**, восстановление не планируется.
- **Веб-интерфейс:** https://fssp.gov.ru/iss/ip — Банк данных исполнительных производств. Защищён капчей.
- **Коммерческие:** checko.ru (до 50 запросов/день бесплатно), DaMIA, api-cloud.

## Что берём для конвейера

| Поле | Тип | Описание | Зачем |
|---|---|---|---|
| case_number | string | Номер исполнительного производства | идентификация |
| date_opened | date | Дата возбуждения | информационно |
| subject | string | Предмет исполнения | информационно |
| amount | number | Сумма задолженности (₽) | стоп-фактор 5, повод 8 |
| department | string | Отдел судебных приставов | информационно |
| status | string | Статус: active, completed, terminated | фильтрация |

### Кого проверяем

1. **Компанию / ИП** (по ИНН) — стоп-фактор 5: неисполненные исполнительные производства → приостановление операций.
2. **Директора** (по ФИО + дата рождения) — повод 8: неисполненные производства > 10 тыс. ₽ у директора как физлица.


## Примечания

- Стоп-фактор 5 (компания/ИП): любые неисполненные производства → отказ.
- Повод 8 (директор как физлицо): сумма > 10 тыс. ₽ → ручная проверка. Это сигнал, но не приговор для компании.
- Поиск физлица в ФССП идёт по ФИО + дата рождения (ИНН физлица ФССП не использует). Дату рождения берём из аккаунта (регистрация).
