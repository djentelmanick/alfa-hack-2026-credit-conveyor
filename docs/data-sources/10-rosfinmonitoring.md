# Росфинмониторинг — Перечень лиц, причастных к терроризму и экстремизму

## Владелец

Федеральная служба по финансовому мониторингу (Росфинмониторинг).

## Доступ

- **Официальный сайт:** https://fedsfm.ru — перечень публикуется, но формат выгрузки неясен.
- **Для банков:** перечень обновляется через личный кабинет Росфинмониторинга.
- **Публичного API нет.**
- Проверка обязательна по 115-ФЗ «О противодействии легализации (отмыванию) доходов».

## Что берём для конвейера

Проверяем наличие в перечне:
1. **Компании** (по ИНН и наименованию).
2. **Директора** (по ФИО).
3. **Учредителей** (по ФИО).
4. **ИП** (по ФИО).

| Поле | Тип | Описание |
|---|---|---|
| in_list | boolean | Находится ли в перечне |
| list_type | string\|null | terrorist / extremist / null |
| entry_date | date\|null | Дата включения в перечень |
| reason | string\|null | Основание включения |

Если хотя бы один из проверяемых в перечне → **стоп-фактор 7** → отказ.

## Контракт мока

```
GET /api/mock/rosfinmonitoring/check

Query params:
  type=company|person
  // для company:
  inn=7726402390
  name=ООО "М-ФУД"
  // для person:
  last_name=СОТИР
  first_name=ДМИТРИЙ
  patronymic=ГЕОРГИЕВИЧ

Response 200:
{
  "subject": "ООО \"М-ФУД\"",
  "type": "company",
  "in_list": false,
  "list_type": null,
  "entry_date": null,
  "reason": null
}

// В перечне
{
  "subject": "ИВАНОВ ИВАН ИВАНОВИЧ",
  "type": "person",
  "in_list": true,
  "list_type": "extremist",
  "entry_date": "2024-03-15",
  "reason": "Решение суда от 01.03.2024"
}

Response 503:
{"error": "service_unavailable", "message": "Росфинмониторинг не отвечает"}
```

## Примечания

- Для демо: мок возвращает `in_list: false` по умолчанию. Для специального тестового ИНН/ФИО — `true`.
- Размер реального перечня: 600+ организаций, 16 000+ физлиц (на конец 2024 года).
- Последствия попадания: арест всех счетов, ограничения на распоряжение имуществом.
- На каждого учредителя и директора нужен отдельный запрос.
