# Выписка 1С (1CClientBankExchange)

## Владелец

Формат определён фирмой «1С». Файл выгружает клиент из своего интернет-банка.

## Доступ

Клиент загружает файл в анкету. Парсим на бэкенде.

## Формат файла

Текстовый файл в кодировке Windows-1251 (иногда UTF-8). Структура:

```
1CClientBankExchange
ВерсияФормата=1.03
Кодировка=Windows
Отправитель=Банк
Получатель=
ДатаСоздания=24.10.2026
ВремяСоздания=15:30:00
ДатаНачала=01.04.2026
ДатаКонца=24.10.2026
РасчетныйСчет=40702810123456789012
СекцияДокумент=Платежное поручение
Номер=123
Дата=15.10.2026
Сумма=150000.00
ПлательщикСчет=40702810123456789012
Плательщик=ООО "М-ФУД"
ПлательщикИНН=7726402390
ПолучательСчет=40702810987654321098
Получатель=ООО "Поставщик"
ПолучательИНН=7701234567
НазначениеПлатежа=Оплата по договору №45 от 01.10.2026 за продукты питания
КонецДокумента
```

### Ключевые поля заголовка

| Поле | Описание | Зачем |
|---|---|---|
| ДатаНачала | Начало периода выписки | проверка: период ≥ 6 месяцев |
| ДатаКонца | Конец периода выписки | проверка: последняя операция не старше месяца |
| РасчётныйСчет | Номер расчётного счёта | информационно |

### Ключевые поля документа (операции)

| Поле | Описание | Зачем |
|---|---|---|
| Дата | Дата операции | группировка по месяцам |
| Сумма | Сумма операции | расчёт оборотов |
| ПлательщикИНН | ИНН плательщика | проверка: ИНН совпадает с ИНН заявки |
| ПолучательИНН | ИНН получателя | определение направления (входящий/исходящий) |
| Плательщик | Наименование плательщика | top payers для отчёта |
| Получатель | Наименование получателя | информационно |

## Проверки на этапе 2 (CHECKING)

1. **ИНН в выписке = ИНН заявки** — ПлательщикИНН или ПолучательИНН должен совпадать с ИНН компании.
2. **Период ≥ 6 месяцев** — ДатаКонца − ДатаНачала ≥ 6 мес, иначе дозапрос.
3. **Свежесть** — последняя операция не старше 1 месяца от даты подачи заявки, иначе дозапрос.
4. **Подлинность** — проверка ЭП банка (см. 05-bank-signature.md) или сверка с ФНС (см. 07-gir-bo.md).
