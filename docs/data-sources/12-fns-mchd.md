# Реестр машиночитаемых доверенностей (ФНС)

## Владелец

ФНС России. С 1 сентября 2024 года сотрудники и представители организаций подписывают электронные документы своей подписью физлица вместе с МЧД, а МЧД регистрируется в распределённом реестре ФНС.

## Доступ

- Реальная проверка — открытый сервис ФНС проверки МЧД ([m4d.nalog.gov.ru](https://m4d.nalog.gov.ru)): по номеру (GUID), ИНН доверителя и ИНН представителя возвращает статус, срок и полномочия. Без GUID проверить нельзя.
- Для MVP — чистый мок на синтетике `backend/app/infra/mocks/data/mchd.json`.

## Что проверяем

1. Доверенность найдена и не отозвана, срок не истёк.
2. Доверитель — компания из заявки.
3. Доверенность подписал действующий руководитель по ЕГРЮЛ (доверенность прежнего директора не проходит).
4. Представитель — заявитель (по ИНН из аккаунта).
5. Есть оба полномочия: подача заявки на кредит и подписание кредитного договора.

XML доверенности и открепленную подпись доверителя (`.sig`) в MVP не загружаем и не проверяем. С 1 февраля 2026 года паспортные данные в МЧД необязательны, поэтому мок их не содержит.

## Контракт мока

```
POST /api/mock/mchd/find

Body:
{
  "guid": "5f0c2b9e-1d4a-4c6b-9a7e-2b8f3c1d0e01",
  "principal_inn": "7715012342",
  "representative_inn": "771502345660"
}

Response 200 (найдена):
{
  "found": true,
  "guid": "5f0c2b9e-1d4a-4c6b-9a7e-2b8f3c1d0e01",
  "principal": {"inn": "7715012342", "full_name": "ООО \"ХЛЕБНЫЙ ДВОР\""},
  "signed_by": {"inn": "771501234573", "full_name": "МОРОЗОВ СЕРГЕЙ ПЕТРОВИЧ"},
  "representative": {"inn": "771502345660", "full_name": "ВАСИЛЬЕВА АННА ИГОРЕВНА"},
  "issued_at": "2026-10-01",
  "valid_until": "2027-10-31",
  "status": "active",                       // active | revoked
  "powers": ["LOAN_APPLICATION", "LOAN_AGREEMENT_SIGNING"]
}

Response 200 (не найдена или не совпал ИНН доверителя или представителя):
{"found": false}

Response 503:
{"error": "service_unavailable", "message": "Реестр МЧД не отвечает"}
```

Коды полномочий условные: классификатор полномочий ФНС мок не воспроизводит.

## Примечания

- Для демо: учётка `buh` (бухгалтер ООО «Хлебный двор») с МЧД `…0e01` проходит; `lebedev` (учредитель ООО «Техпром») с МЧД `…0e02` получает отказ: нет полномочия на подписание кредитного договора.
- Записи `…0e03` (отозвана), `…0e04` (истекла), `…0e05` (подписал прежний директор) нужны для тестов.
